
# bootc-broccoli

![bootc broccoli](/scrot/broccoli.png)

It is not all that important.

Veggies are good for you. Bootc is good for you.

Hence bootc-broccoli, where I mix and stir-fry anything. 

Nov 2, 2026: Currently on the menu: an adjusted Aurora image (based on ublue-os/aurora:testing).

From the terminal flatpak and distrobox are available. You can easily install an appstore like Easyflatpak. I install my applications from the cli.

Make sure to run "ujust aurora-cli" after first login. It will install things like eza, zoxide and starship for you.

---------

KISS. Install any Fedora-based bootc image first (Silverblue, Kinoite, Bluefin). 

Then:

        sudo bootc switch ghcr.io/thedanangineer/bootc-broccoli


Currently the image gets renewed every Monday, Wednesday and Friday, so sit back and relax.
